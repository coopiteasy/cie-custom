This module extends the functionality of point of sale module, to
add custom informations and features for the UGESS Project.

**On the order summary**

- It displays the ceiling and the remaining amount.

.. figure:: https://raw.githubusercontent.com/coopiteasy/cie-custom/16.0/ugess_pos/static/description/order_summary_positive.png

.. figure:: https://raw.githubusercontent.com/coopiteasy/cie-custom/16.0/ugess_pos/static/description/order_summary_negative.png

**On the customer list view**

- it displays the ceiling of each customer, with start of the
  the ceiling, and the current total of the period.

- it displays an household summary text.

.. figure:: https://raw.githubusercontent.com/coopiteasy/cie-custom/16.0/ugess_pos/static/description/customer_list.png

**On the receipt**

- it replaces the "discount" word by "Savings Achieved"

- it displays ceiling and remaining amount

.. figure:: https://raw.githubusercontent.com/coopiteasy/cie-custom/16.0/ugess_pos/static/description/receipt.png

**Adds constrains**

- it prevents to make an order with normal products and
  membership products.
